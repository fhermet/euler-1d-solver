1D Euler Equations Solver

Compare 59 finite volume schemes on compressible gas dynamics problems. MUSCL, WENO, Roe, HLLC, Godunov and more — with convergence analysis and Fourier diagnostics.

Launch App GitHub

Features

59 Numerical Schemes

11 standalone flux solvers combined with 6 high-order reconstructions (MUSCL, ENO2, WENO3, WENO5) and 5 slope limiters.

Exact Riemann Solver

Full exact solution for reference: Newton iteration on pressure with PVRS initial guess, vectorized NumPy sampling.

Convergence Studies

Mesh refinement with L1, L2, Linf error norms. Automatic order estimation by log-log regression.

Fourier Analysis

Numerical dissipation and dispersion curves for every scheme. Linearized analysis around a uniform state.

Time Integration

RK1 through RK5 (Dormand-Prince). Adaptive time stepping with CFL condition. SSP-RK3 for TVD preservation.

9 Test Cases

Classical Riemann problems (Sod, Lax, Shu-Osher, two shocks) and smooth solutions (entropy wave, acoustic wave) for order verification.

Available Schemes

Flux Solvers (order 1)

  • Godunov (exact)
  • Roe (+/- entropy fix)
  • HLLC / HLL
  • Rusanov
  • AUSM+ / AUSM+-up
  • Lax-Friedrichs
  • Lax-Wendroff
  • JST

Reconstructions

  • MUSCL (order 2)
  • ENO2 (order 2)
  • WENO3 JS/Z (order 3)
  • WENO5 JS/Z (order 5)

Slope Limiters

  • Minmod
  • Van Leer
  • Superbee
  • MC (monotonized central)
  • Van Albada

Test Cases

  • Sod shock tube — rarefaction + contact + shock
  • Lax problem — stronger waves than Sod
  • Double rarefaction — symmetric rarefactions, near-vacuum
  • Stationary contact — pure numerical diffusion measurement
  • Near vacuum — extreme double rarefaction (93% of vacuum threshold)
  • Two shocks — strong shock collision (Toro test 4)
  • Shu-Osher — Mach 3 shock in sinusoidal density
  • Entropy wave — smooth advection for order verification
  • Acoustic wave — isentropic perturbation for order verification
